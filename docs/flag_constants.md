# Flag Constants

Mentor Rookie stores active relationship state on brother flags. These flags are persisted in save data, so the underlying string values must stay stable unless a save migration is added.

Active relationship flags are defined once in `::MentorRookie.Flags`:

- `Role`
- `PartnerID`
- `BattlesTogether`
- `FocusAttributeID`
- `FocusedTrainingBattles`
- `FocusedTrainingGain`

Use these constants instead of hard-coded string literals when reading, writing, or removing active relationship flags.

Pair history uses the dynamic `MentorRookieHistory_<mentorID>_<rookieID>_` prefix. That prefix is also centralized as `::MentorRookie.Flags.HistoryPrefix`, but each full history flag is still generated by helper functions because it depends on actor IDs.
